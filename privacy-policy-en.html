Privacy Policy

Last updated: November 9, 2025

1. Introduction

Rise Against Hunger Italia ("we", "our") respects the privacy of our users ("user" or "you"). This Privacy Policy explains how we collect, use, and protect your information when you use our Rise Against Hunger Italia mobile application.

2. Information We Collect

The Rise Against Hunger Italia application is designed to fully respect user privacy and does NOT collect any personal data.

Data we DO NOT collect:

  • Authentication data: the app does not require registration, login, or user accounts
  • Personal information: no names, emails, phone numbers, or other identifying information
  • Geolocation data: no access to device GPS location
  • User preferences: no storage of settings or customizations on the device
  • Usage data: no tracking, analytics, or monitoring of in-app activities
  • Advertising identifiers: the app does not display ads and does not use advertising IDs
  • Cookies or tracking technologies: no activity tracking

Type of application:

Rise Against Hunger Italia is a purely informational application that displays static content about the organization's humanitarian projects. All displayed data (number of meals, projects, volunteers) is embedded in the application and does not require any collection of information from users.

3. Over-The-Air (OTA) Updates

The application uses the Expo Updates service to receive automatic application code updates. This process:

  • Does not collect personal data: only downloads updated application code
  • Does not send identifying information: the device only requests if updates are available
  • Serves exclusively to provide bug fixes and new features
  • Occurs transparently: users see a progress screen during download

4. Data Retention Period

Not applicable: since the application does not collect any personal data, there is no retention period to specify.

5. Third-Party Services

The application uses the following technical services, which do not collect users' personal data:

  • Expo Updates: service for distributing application updates (no user data transmitted)
  • Static content: images and texts embedded in the application without connections to external servers during normal use

Important note: the application can function completely offline after the first download. It does not require an internet connection to view content, except to receive optional OTA updates.

6. User Rights

Important note: Since the application does not collect, store, or process personal data, the rights provided by GDPR (access, rectification, deletion, restriction, portability, objection) are not applicable as there is no personal data to manage.

For any questions or clarifications about privacy and data processing, users can still contact the Data Controller at: privacy@riseagainsthunger.it

7. Security

Not applicable: since the application does not collect, store, or transmit personal data, there are no data security measures to implement. The application operates completely locally on the user's device.

8. Changes to This Policy

This Privacy Policy may be updated periodically. Significant changes will be communicated to users through the application or by publication on the website. We recommend regularly consulting this page to verify any updates.

9. Data Controller and Contact

  • Email: privacy@riseagainsthunger.it
  • Website: italy.riseagainsthunger.org

Users can contact the Data Controller at the addresses above for any questions or information regarding privacy and data processing.
