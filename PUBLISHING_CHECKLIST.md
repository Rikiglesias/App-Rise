# 📋 Checklist Publishing - Rise Against Hunger Italia

## 🔧 **Preparazione Tecnica**

### App Configuration

- [ ] Nome app corretto in `app.json`
- [ ] Bundle identifier iOS configurato
- [ ] Package name Android configurato  
- [ ] Versione e build number aggiornati
- [ ] Descrizione app completata
- [ ] Permessi necessari dichiarati

### Assets

- [ ] **Icon**: 1024x1024px preparata
- [ ] **Splash Screen**: Dimensioni corrette
- [ ] **Screenshots**: Per entrambe le piattaforme
  - iPhone: 6.7", 5.5", 6.5"
  - iPad: 12.9", 11"
  - Android: Phone, Tablet, TV

### Funzionalità

- [ ] Tutte le sezioni implementate o placeholder eleganti
- [ ] Navigazione fluida testata
- [ ] App testata su dispositivi reali
- [ ] Performance ottimizzate
- [ ] Gestione errori implementata

## 🍎 **iOS App Store**

### iOS Account Setup

- [ ] Apple Developer Account attivo ($99/anno)
- [ ] App creata in App Store Connect
- [ ] Certificati iOS configurati
- [ ] Team ID ottenuto

### App Store Connect

- [ ] Metadata compilati:
  - [ ] Nome app
  - [ ] Sottotitolo (max 30 caratteri)
  - [ ] Descrizione (max 4000 caratteri)
  - [ ] Parole chiave (max 100 caratteri)
  - [ ] URL supporto
  - [ ] URL privacy policy
- [ ] Screenshots caricati
- [ ] Rating età appropriato
- [ ] Prezzi configurati (Gratuita)

### Build Upload

- [ ] EAS configurato per iOS
- [ ] Build production creata
- [ ] TestFlight testing completato
- [ ] Build sottomessa per review

### Review Checklist iOS

- [ ] App funziona senza crash
- [ ] Rispetta Human Interface Guidelines
- [ ] Non viola content policy
- [ ] Privacy policy presente se necessaria
- [ ] Funzionalità descritte accuratamente

## 🤖 **Android Google Play**

### Android Account Setup

- [ ] Google Play Developer Account ($25 una tantum)
- [ ] App creata in Play Console
- [ ] Service Account configurato per EAS

### Play Console

- [ ] Store listing compilato:
  - [ ] Titolo app (max 50 caratteri)
  - [ ] Descrizione breve (max 80 caratteri)
  - [ ] Descrizione completa (max 4000 caratteri)
  - [ ] Contatti sviluppatore
- [ ] Screenshots caricati
- [ ] Rating contenuti completato
- [ ] Prezzi configurati

### Release

- [ ] EAS configurato per Android
- [ ] AAB (Android App Bundle) creato
- [ ] Internal testing completato
- [ ] Closed testing (optional)
- [ ] Production release pubblicato
